# G360iA Web - Landing & Portfolio Site

**Sitio web profesional de AgenciaNLMD - Portfolio, Blog y Marketing**

G360iA Web es el sitio web público de presentación de AgenciaNLMD. Combina landing page, portfolio de proyectos, blog, y sistema de contacto integrado con chatbot inteligente para captura de leads.

## 🎯 Características

- **Landing Page** - Presentación profesional de AgenciaNLMD
- **Portfolio** - Galería de proyectos realizados con detalles técnicos
- **Blog** - Artículos sobre tecnología, desarrollo y negocios
- **Chatbot Inteligente** - Asistente 24/7 para consultas de clientes
- **Formulario de Contacto** - Captura de leads con validación
- **Descarga CV** - CV descargable en múltiples idiomas (ES/EN)
- **Imagen OG Dinámica** - Generación de previsualizaciones para redes sociales
- **Responsive Design** - Optimizado para móvil, tablet y desktop
